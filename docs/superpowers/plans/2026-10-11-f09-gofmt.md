> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Report `gofmt -l` formatting drift as per-file warning findings instead of silently discarding successful stdout.

**Architecture:** Change the `Spawner` contract to carry success stdout, add a per-tool interpreter registry (`gofmt` real, everything else byte-identical default), and plumb the PR-changed file set from the already-parsed diff into `runL2`. ### Task 52: F09 — spawner stdout + gofmt interpreter

**Files:**
- Modify: `src/l2.ts` (`Spawner`, `execTool`, interpreter registry, `runOne`, `runL2` signature)
- Test: `tests/l2.test.ts` (new tests + spawner-fake migration)

**Interfaces:**
- Consumes: `ToolFailure`, `L2_TIMEOUT_MS`, `describeFailure`, `l2Argv`, `detectL2Tools` (all existing, unchanged).
- Produces: `export interface SpawnResult { failure: ToolFailure | undefined; stdout: string }`; `export type Spawner = (cmd: string, args: string[], cwd: string, timeoutMs?: number) => Promise<SpawnResult>`; `interpretGofmt(name: string, failure: ToolFailure | undefined, stdout: string, changed: Set<string>): Finding[]` (the spec's uniform `Interpreter` signature); `runL2(dir: string, spawn?: Spawner, timeoutMs?: number, changedFiles?: Set<string>)`.

**Exact behavior:**
- `execTool` resolves `{ failure: undefined, stdout }` on success (stdout captured, never discarded); on failure resolves `{ failure: {...unchanged shape...}, stdout }` with raw stdout.
- `interpretGofmt`: split on `\n`, drop empties, strip one leading `./`, intersect with `changed`; per surviving file `{ severity: "warning", file: <path>, rule: "gofmt", message: "gofmt: <path> is not formatted (run gofmt -w <path>)" }`. Invoked regardless of exit code. When no files parse AND a `failure` is present, it delegates to the default interpreter below (so a nonzero exit with an empty/unparseable file list still yields today's generic finding — the existing stderr-only exit-3 test depends on this).
- Default interpreter (every other tool): `undefined` failure or `ENOENT` → no finding; else today's single generic warning (same `describeFailure` + first-5-lines detail).
- `runOne` dispatches by tool name (gofmt → `interpretGofmt`, else default); the `ENOENT` short-circuit stays in `runOne` before dispatch, as today. `runL2` threads `changedFiles` (default `new Set()`) to the interpreter.

```ts
it("gofmt exit 0 with a file list reports one warning per changed file", async () => {
  const spawn = async () => ({ failure: undefined, stdout: "a.go\nsub/b.go\nc.go\n" });
  const findings = await runL2("tests/fixtures/go", spawn, 1000, new Set(["a.go", "sub/b.go"]));
  expect(findings).toEqual([
    { severity: "warning", file: "a.go", rule: "gofmt", message: "gofmt: a.go is not formatted (run gofmt -w a.go)" },
    { severity: "warning", file: "sub/b.go", rule: "gofmt", message: "gofmt: sub/b.go is not formatted (run gofmt -w sub/b.go)" },
  ]);
});
it("gofmt ignores unchanged files, empty output, and ./ prefixes", async () => {
  const onlyUnchanged = async () => ({ failure: undefined, stdout: "other.go\n" });
  expect(await runL2("tests/fixtures/go", onlyUnchanged, 1000, new Set(["a.go"]))).toEqual([]);
  const empty = async () => ({ failure: undefined, stdout: "" });
  expect(await runL2("tests/fixtures/go", empty, 1000, new Set(["a.go"]))).toEqual([]);
  const dotted = async () => ({ failure: undefined, stdout: "./a.go\n" });
  expect(await runL2("tests/fixtures/go", dotted, 1000, new Set(["a.go"]))).toEqual([
    { severity: "warning", file: "a.go", rule: "gofmt", message: "gofmt: a.go is not formatted (run gofmt -w a.go)" },
  ]);
  // Omitted changedFiles defaults to an empty set: silence, never a whole-repo dump.
  const listed = async () => ({ failure: undefined, stdout: "a.go\nsub/b.go\n" });
  expect(await runL2("tests/fixtures/go", listed, 1000)).toEqual([]);
});
it("gofmt nonzero exit with a file list still reports the files", async () => {
  const spawn = async () => ({ failure: { code: 2, signal: null, output: "boom" }, stdout: "a.go\n" });
  expect(await runL2("tests/fixtures/go", spawn, 1000, new Set(["a.go"]))).toEqual([
    { severity: "warning", file: "a.go", rule: "gofmt", message: "gofmt: a.go is not formatted (run gofmt -w a.go)" },
  ]);
});
it("real execTool captures success stdout (shell stub, no Go toolchain)", async () => {
  const bin = makeTmp({ gofmt: "#!/bin/sh\nprintf 'a.go\\n'\n" });
  chmodSync(join(bin, "gofmt"), 0o755);
  const oldPath = process.env.PATH;
  process.env.PATH = bin; // `go` is absent here → ENOENT → skipped
  try {
    expect(await runL2("tests/fixtures/go", execTool, 10000, new Set(["a.go"]))).toEqual([
      { severity: "warning", file: "a.go", rule: "gofmt", message: "gofmt: a.go is not formatted (run gofmt -w a.go)" },
    ]);
  } finally {
    process.env.PATH = oldPath;
  }
});
```
